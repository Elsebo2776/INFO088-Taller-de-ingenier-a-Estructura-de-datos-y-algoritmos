## resumen del trabajo:

Se construirán distintos métodos de almacenamiento trabajados para recorrer diccionarios en orden lexicografico haciendo busquedas, insersiones y eliminaciones con el uso de STL y midiendo el tiempo para cada solución.

Este trabajo consta de dos soluciones, la solución 1, usando arreglos dinamicos ordenados, es decir Arrays o Vector y la solucion 2, usando una lista circular doblemente enlazada, manejando punteros.
